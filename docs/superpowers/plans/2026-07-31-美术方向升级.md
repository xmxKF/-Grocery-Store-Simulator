## Global Constraints

- Three.js **r128 UMD**，经典 `<script>`，全局 `THREE`。无 CapsuleGeometry / RoundedBoxGeometry。
- **无构建、无 ES modules、零网络请求**、file:// 即玩；美术资产只允许代码生成。
- ES5（`var`/`function`）、IIFE + `'use strict'`、只挂 `window.G`。
- **本构建 shader 缺 `USE_INSTANCING_COLOR`**：`setColorAt`/`instanceColor` 静默无效，**绝对禁用**；实例颜色靠 per-pid 材质。
- **InstancedMesh 必须 `frustumCulled = false`**（r128 无 computeBoundingSphere）。
- **传送带材质 `.color` 恒为 `0x4E5866`**（checkout.findBeltMesh 靠色值定位）；**纸箱材质保持 `color.set()` 语义**（updateBoxVisual 满/空切换）。
- **不开 `outputEncoding=sRGBEncoding`、不开 toneMapping**。
- 价签的几何尺寸与位置**不得改动**（occluded() 容差余量仅 0.01m）。
- lowfx：`localStorage['gss-lowfx']==='1'` → 纹理生成器全返回 null + shadowMap 关。
- 商品基础几何 XZ 包络 ≤ **0.16m**（tray 0.17 躺放例外）；单件 ≤100 三角。

  function ensurePool(pid, need) {
    var pool = instPools[pid];
    if (pool && pool.cap >= need) return pool;
    var cap = pool ? pool.cap : 64;
    while (cap < need) cap *= 2;
    var mesh = new THREE.InstancedMesh(itemGeoFor(pid), itemMatFor(pid), cap);
    mesh.count = 0;
    mesh.frustumCulled = false;                 // r128 无 computeBoundingSphere，必关

    if (pool && pool.mesh.parent) pool.mesh.parent.remove(pool.mesh);
    if (pool) pool.mesh.dispose();
    if (sceneRef) sceneRef.add(mesh);
    instPools[pid] = { mesh: mesh, cap: cap };

    for (var i = 0; i < flights.length; i++) {
      if (flights[i].slot === slot && flights[i].pid === pid) n++;

  function applyGait(c, dt, moving) {
