# 小店经营者

## 游戏简介

《小店经营者》是一款第一人称的小型超市经营模拟游戏，在浏览器里直接运行，无需安装、无需联网。

你是一家 16m × 12m 小超市的老板兼唯一员工：用后墙的仓储电脑订货，把送到卸货区的纸箱一件件搬上货架，给每样商品定价，然后开门营业——顾客进店挑货、排队结账，你要亲手在收银台逐件扫码、收现金找零或刷卡。一天结束后结算营业额、进货成本与固定支出，攒钱扩品类、攒经验升等级，解锁更多货架、冷藏柜和商品。

技术上是一份「零依赖」的实现：Three.js r128（UMD，本地 `libs/`）+ 原生 JavaScript，没有构建步骤、没有 ES modules、运行时零网络请求，全部美术资源由代码用基础几何体和纯色现场生成。

## 如何开始

1. **双击 `index.html`** 即可开始游戏。
2. 推荐使用 **Microsoft Edge** 或 **Google Chrome**（桌面版）。游戏需要 WebGL 与指针锁定（Pointer Lock）支持。
3. 如果浏览器拦截了本地文件（`file://`）的读取，用任意静态服务器打开即可，例如在项目根目录执行：

   ```
   python -m http.server 8080
   ```

   然后访问 `http://localhost:8080/index.html`。（也可用 `npx serve`、VS Code 的 Live Server 等任意等价方案。）

4. 进入主菜单后点「新游戏」开始；有存档时可点「继续」。存档自动保存在浏览器的 `localStorage`（键名 `gss-save-v2`），每天结算进入次日时自动写入。

> 自测：在地址栏加上 `?selftest=1`（例如 `index.html?selftest=1`）会跳过菜单，脚本化跑一遍「订货 → 送达 → 上架 → 营业 → 顾客结账 → 日结算 → 存读档」全流程，并把结果写入页面标题与隐藏的 `#selftest` 节点。

> 开发者测试入口：地址栏加上 `?dev=1`（例如 `index.html?dev=1`）会载入一个「全开」起点——Lv10、四类许可证齐、三区全开、三台收银台、¥50000、货架灌满、仓库/卸货区/店内地面预置 10 只箱，用于跳过前期爬坡直接测功能（等级与许可证门槛逻辑本身一条不改，只是状态已满足）。
> **该模式使用独立存档键 `gss-save-dev`，绝不读写你的真实存档（`gss-save-v2` / `gss-save-v1`）**：在开发模式里随便玩、随便打烊，退出后按正常方式打开 `index.html` 进度分毫未动。`?dev=1` 与 `?selftest=1` 同时出现时以自测优先，`dev` 被忽略。

## 操作表

| 键 | 功能 |
|---|---|
| 点击画面 | 进入指针锁定（Pointer Lock） |
| `WASD` | 移动；`Shift` 冲刺 |
| 鼠标 | 视角 |
| `E` / 左键 | 交互：捡箱 / 上架 1 件 / 开电脑 / 进收银台 / 丢箱 / 扫码 |
| `Q` | 放下手中箱子到脚下 |
| 右键（按住 / 松开） | 持箱时蓄力投掷：按住蓄力（0.8s 满），松开扔出；与准星指向何处无关 |
| `Tab` | 打开/关闭仓储电脑界面 |
| `O` | 开门营业 / 提前打烊 |
| `Esc` | 关闭当前界面 / 退出收银台 / 释放指针锁定 |

## 玩法目标

**一天的循环**

1. **备货阶段**（时钟暂停）：按 `Tab` 打开仓储电脑，在「订货」页把商品加入购物车下单（单次最多 8 箱，等级 9 后 12 箱），25 秒后箱子送到门外卸货区；在「定价」页调整售价；在「许可证」页购买新类目的经营许可。
2. **上架**：走到卸货区对准纸箱按 `E` 举起（举箱时移速下降），走到货架格前按住 `E` 逐件上架。生鲜类只能放冷藏柜，其他类目不能放冷藏柜。箱子清空后变暗，拿去垃圾桶丢掉可 +1 XP。
3. **营业**：按 `O` 开门，店内时钟从 09:00 走到 21:00（300 秒实时）。顾客按等级与天数决定的频率进店，只买货架上有货的商品，售价相对市场价越高，放弃购买甚至抱怨的概率越大。
4. **收银**：跑到收银台按 `E` 进入收银模式，左键逐件点击传送带上的商品扫码（每件 +2 XP），点「结算」后随机刷卡或收现金。现金要自己用面额按钮拼出找零：找准 +3 XP，多找会赔钱，少找顾客投诉。漏扫的商品等于白送。
5. **打烊结算**：时钟走完（或提前按 `O`）后停止进客，场内顾客走完即弹出日结算：营业额 − 进货成本 − 固定支出（房租 + 水电 + 员工工资）= 净利。点「进入第 N 天」自动存档并进入次日备货。

**长期目标**

- 每天净利为正，攒钱买【日用品】【生鲜】许可证，解锁更多商品线。
- 攒 XP 升级：Lv3 / Lv6 / Lv8 增加货架组数（24 → 30 → 36 → 48 格），Lv8 触发店铺扩建（房租涨到 ¥80，同屏顾客上限 +2），Lv9 提高单次订货上限，Lv10 可花 ¥200 雇佣站桩收银员（每天 ¥60 工资，自动结账但只给一半 XP）。
- **注意破产规则**：余额可以为负，但连续 3 天日结算余额为负就会倒闭回到主菜单（存档保留，可以从主菜单继续重开）。
